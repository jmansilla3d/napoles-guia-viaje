# Guía de Nápoles

Guía de bolsillo con itinerario y 45 recomendaciones enlazadas a Google Maps.

Descarga `index.html` y ábrelo en un navegador. Es un archivo independiente, sin instalación ni dependencias externas.

Incluye un buscador y un botón para imprimir o guardar como PDF. Los enlaces de Google Maps requieren conexión a internet.

Información consultada el 20 de septiembre de 2026. Fechas, horarios y precios sujetos a confirmación. No se han realizado reservas.
